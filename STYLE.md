# TD Gwen — Art Direction (STYLE.md)

Neon vector on dark indigo. Everything is code-generated canvas 2D; no image
assets, no audio files, no web fonts. The `t` parameter passed to every draw
function is a seconds animation clock (monotonic, wrap-safe).

## Palette

| Role            | Hex        | Usage                          |
|-----------------|------------|--------------------------------|
| bg              | `#0b0e22`  | page + canvas background       |
| grid line       | `rgba(255,255,255,.05)` | cell grid lines   |
| path fill       | `#1a2040`  | walkable lane                  |
| path edge glow  | `#37e6ff`  | 2px stroke around the path     |
| accent          | `#37e6ff`  | UI borders, selected ring      |
| gold            | `#ffd166`  | currency, support tower        |
| hp bar fill     | `#4dff9c`  | enemy health bars              |
| shadow          | `rgba(0,0,0,.35)` | radial gradients ONLY     |

### Towers (glyph color)

| Type    | Color    | Glyph                              |
|---------|----------|------------------------------------|
| arrow   | `#4dff9c`| chevron                            |
| cannon  | `#ffb347`| hexagon                            |
| frost   | `#7fd4ff`| ring / snowflake                   |
| support | `#ffd166`| double-ring + core                 |
| sniper  | `#c77dff`| long diamond                       |

Level pips: small dots orbiting the glyph at radius ~0.42*CELL, angular speed
~1.2 rad/s, count = level (L1:1, L2:2), pip radius 2.5px, color = tower color.

### Enemies

| Type    | Color    | Glyph                                |
|---------|----------|--------------------------------------|
| grunt   | `#ff6b6b`| blob (soft circle, squash wobble)    |
| runner  | `#ffd166`| sleek dart (elongated triangle)      |
| tank    | `#8d99ae`| chunky octagon                       |
| flyer   | `#ff9ff3`| winged triangle, NO ground shadow    |
| shield  | `#54a0ff`| hexagon + front plate                |
| boss    | `#f368e0`| big core + rotating ring (~3x grunt) |

Enemy sprite radius = `r * CELL` px (from ENEMY_TYPES). Wobble: `sin(t*6 + id)`
offset ±0.05*r for grunts/runners only. Boss ring rotates at 0.8 rad/s.

## Sprite sizes

All in logical px (CELL = 48):

- Tower body fits within 0.8*CELL of its cell center.
- Enemy drawn at `r*CELL` radius per type (grunt 13.4px … boss 28.8px).
- Projectile core 4–6px; trail length ~18–30px behind velocity direction.
- HP bar: width = 2*rPx, height 4px, positioned 4px above the enemy top.
  Background `rgba(0,0,0,.5)`, fill `#4dff9c` scaled by hpFrac.

## Animation specs (t = seconds)

- **Towers**: idle bob `sin(t*2 + x*0.05)` ±1px on non-support towers;
  support pulses its rings (alpha 0.6+0.3*sin(t*3)); muzzle flash 0.08s after
  fire (cd just reset) — brighten core 1.5x.
- **Enemies**: movement follows path exactly; add the wobble above; flyers
  bob vertically ±2px at 3 rad/s (cosmetic only).
- **Projectiles**: additive trail (`globalCompositeOperation='lighter'`),
  3 fading segments; sniper draws a thin straight beam while piercing.
- **Particles**: lifetime 0.3–0.6s, ease-out fade; kinds below.
- **Path**: static; edge glow alpha oscillates 0.8→1.0 at 0.5 Hz.

## Particle specs

Kinds (all additive, `lighter` composite):

- **burst**: 6–10 short-lived sparks from a point, random angles, speed
  40–120px/s, lifetime 0.3–0.5s, size 2–3px, color = source tower/enemy.
- **ring**: expanding circle stroke, r 4→24px over 0.4s, alpha 0.8→0, used
  for explosions/support ticks.
- **spark**: single streak along a direction, 0.3s, used for kill hits.

Cap: particle pool fixed at 256; oldest recycled when full.

## Shadow rule

Soft shadows are **radial gradients only** (`createRadialGradient`,
`rgba(0,0,0,.35)` → transparent), drawn as an ellipse under grounded sprites.
**NO `ctx.filter`, NO blur filters** anywhere (performance budget). Flyers
and projectiles cast no shadow.

## Typography / UI

- Font: `system-ui`, weight 700 for labels; uppercase labels with
  `letter-spacing:.05em`.
- Panels: translucent `rgba(13,16,38,.85)`, 1px border
  `rgba(55,230,255,.25)`, corner radius 8px.
- Accent `#37e6ff` for interactive highlights; gold `#ffd166` for currency.
- Buttons: same panel style, hover brightens border to `.6`, active state
  fills `rgba(55,230,255,.15)`.
- Toasts: bottom-center, 2s, slide-up + fade.

## Icon design

Arrow-tower neon chevron glyph on `#0b0e22`, rounded-square mask (radius
18%). Rendered by `tools/icon-canvas.html` (canvases #icon-512, #icon-192);
placeholder PNGs generated by `tools/icon-gen.py`. Art job regenerates both
PNGs from the HTML via python playwright.
